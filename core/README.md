# Core Engine Package

This directory contains the foundational systems and configurations for **MOMENTUM: Chrono Blade**.

## Files & Purposes

- [`constants.py`](file:///C:/Users/moham/Downloads/momentum_game/core/constants.py): Master gameplay constants, color palettes (cyber noir & crimson red), weapon configs, enemy statistics, time dilation parameters, and display setup.
- [`camera.py`](file:///C:/Users/moham/Downloads/momentum_game/core/camera.py): High-performance 2D dynamic camera system with cursor lookahead, smooth coordinate transformations, dynamic zoom, and trauma-based directional screen shake.
- [`save_manager.py`](file:///C:/Users/moham/Downloads/momentum_game/core/save_manager.py): JSON-based persistent storage for level progression, rank badges (D through S+), speedrun best times, style records, endless survival waves, and custom player settings.
- [`__init__.py`](file:///C:/Users/moham/Downloads/momentum_game/core/__init__.py): Exposes core components for package imports.
